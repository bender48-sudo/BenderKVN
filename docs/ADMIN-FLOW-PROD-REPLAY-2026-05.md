# Админ «Тест флоу» — как смотреть **реальный** прод, а не отдельный тур

**Проблема:** гиды работают, но ощущение «учебника»: демо-кнопки с alert, фейковый текст trial, меню не всегда = то, что жмёт клиент.

**Цель:** владелец в админке видит **тот же UI и те же callback**, что на проде, с пометкой что произойдёт при нажатии.

---

## Три режима (предлагаем)

| Режим | Для кого | Поведение |
|-------|----------|-----------|
| **A. Демо-гид** (сейчас) | Обучение новичку | `admin_demo_*` → alert, БД не трогаем, примеры текста |
| **B. Прод-сим** (нужен) | Проверка «как на проде» | Клавиатура = **реальная** `create_main_menu_keyboard`; кнопки вызывают **те же** handlers, вверху баннер «вы на своём аккаунте» |
| **C. Живой тест** | 100% правда | Второй TG-аккаунт / тестовый номер: `/start` без админ-меню |

**Согласование:** для ежедневной проверки достаточно **B + C**. Режим A оставить для onboarding новых админов.

---

## Что поменять в коде (после согласия)

1. **Меню гида новичка шаг 2** — кнопки `get_trial` / `connect_vpn` / `menu_help` как у пользователя (опция «не выполнять get_trial» если `trial_used`).
2. **Баннер** вверху гида: `🧪 Прод-симуляция: кнопки настоящие, данные — ваш аккаунт`.
3. **Убрать** только alert на «Начать бесплатно» → вместо этого: если `trial_used`, показать **тот же** alert, что видит пользователь.
4. **Диагностика** — оставить; добавить пункт «Откройте Прод-сим шаг 2 и нажмите Подключить VPN».
5. **Не merge** двух markup на шаге подписчика (Telegram ломает edit) — уже вынесено в отдельные клавиатуры для nb; для ex — показывать **скриншот-описание** + кнопку «Открыть моё главное меню» → `back_to_main_menu` с реальным меню.
