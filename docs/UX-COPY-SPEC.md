# UX / Copywriting Spec — BenderVPN

> **Для Cursor:** это пошаговое ТЗ. Каждый раздел содержит точный файл, функцию/строку, старый текст и новый текст.
> Правило: не трогать логику, только тексты кнопок, сообщений и заголовков.
> Приоритет: 🔴 Критично → 🟡 Важно → 🟢 Желательно.

---

## Принцип замены терминологии (везде, глобально)

| Старое | Новое | Причина |
|---|---|---|
| «конфиг» | «настройка» или убрать | Технический термин |
| «ключ» | «VPN» или «доступ» | Непонятно новичку |
| «подписка» | «VPN» или «доступ» | Звучит как платная услуга |
| «ссылка подписки» | «ссылка для подключения» | Непонятно |
| «Мастер настройки» | «Подключить VPN» | Звучит как IT-сервис |
| «Happ» (первое упоминание) | «приложение Happ» | Без контекста не понятно |
| «inbound», «VLESS», «UUID» | убрать из сообщений юзеру | Технический мусор |
| «Mini App» | «наш сайт» или «инструкция» | Не все знают что такое Mini App |
| «🏠 Главное меню» (reply-кнопка) | «◀ Назад» или убрать | Занимает место, дублирует Back |

### Принципы верстки (для web/portal)

- **Цвет состояния**: зелёный = подключён, красный = нет VPN, серый = загрузка
- **Главная кнопка** — всегда одна, крупная, в центре
- **Прогресс-бар трафика** — только если он < 70%, иначе спрятать
- **QR-код** — показывать сразу, не за кнопкой (особенно в mobile)
- **Нет скролла** на главном экране mobile — всё должно влезать без прокрутки
