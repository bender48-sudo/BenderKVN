# P4-DNS-03: гайд пользователя — DNS bootstrap (не полный VPN)

**Статус:** draft для поддержки и portal. **Не** основной SKU BenderVPN — см. **`FAQ.md`**.

---

## Когда это нужно

- Основной VPN (**Happ + подписка**) не открывается из‑за блокировки домена или порта.
- Нужен **первый контакт** с сервисом (проверка, что мы живы) через DNS-туннель.
- **Не** заменяет Xray/Reality VPN для всего трафика.

---

## iPhone / iPad (без jailbreak)

1. Установите клиент с поддержкой **DNS-over-HTTPS** или **DNS tunnel** (по актуальному PoC **P4-DNS-01** — dnstt/slipstream; до go-live — только beta).
2. Получите **ключ/URL** у поддержки (не публикуется массово до PoC).
3. Включите профиль DNS → откройте **`https://k9x2m1.conntest.xyz:8443/start/`** в Safari.
4. Если страница открылась — перейдите к **основному VPN**: бот → Mini App → Happ.

**Ограничение:** многие приложения (Instagram, YouTube) **не** пойдут через DNS-only — нужен полный VPN.

---

## Android

1. Клиент DNS tunnel (см. внутренний PoC **P4-DNS-01**).
2. Импорт ключа из QR или текста.
3. Проверка: браузер → **`/start/`** на :8443.
4. Далее — Happ по инструкции portal.

На Android 13+ может потребоваться разрешение «VPN/DNS» для приложения-клиента.

---

## Windows / Mac

DNS bootstrap **не** целевой сценарий для desktop. Используйте **Happ** или **v2rayN** с подпиской из бота.

---

## Поддержка

- Основной путь: **`/help_connect`** в боте (LTE/TSPU).
- Частые ошибки: portal **`/portal/help/errors/`**.
- DNS bootstrap ≠ оплата и ≠ продление — только аварийный вход.
