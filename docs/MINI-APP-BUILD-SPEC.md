## Что это

## Принципы (не нарушать)

- **Pixel-accurate:** палитра, Onest, отступы, радиусы, бинарный код-фон (~7–10% opacity), пиксель-робот. CSS-переменные из макетов — как есть.
- **Данные из API:** баланс, дни, устройства, тикеты, рефералы — с бэкенда.
- **HONEST-UI:**
  - Устройство: не «iPhone 15» → «Настройка #N · последний клиент INCY · iOS» (`label`, `last_client`, `last_client_version` из cabinet API).
  - Ёмкость 30k: не фейк-счётчик; «счётчик скоро» до `MONITOR-CAPACITY-001`.
  - Ставка: **6,66 ₽/день** (не 6,67). 200 ₽ = 30 дней (kopeks в config).
  - Timestamps — серверные UTC-aware, не клиентские.
  - Колесо — выпадение по **весам** (см. session backlog §6).

## Навигация

- Нижнее меню: **Главная · Доступ · Баланс · Рефералы · Поддержка**.
- Корневые разделы → полная шапка + нижнее меню.
- Вложенные (чат, визард, деталка, партнёрский кабинет) → «← заголовок», без нижнего меню.
- Бургер: разделы + «Выйти». Фортуна — «Скоро» или отдельная кнопка.
- RU/EN — рабочий переключатель.

## Технические заметки

- `telegram-web-app.js` — юзер/тема из TG.
- **INVITE-ONLY:** гейт на **боте**; в мини-апке экрана-стены нет.
- Суммы: kopeks внутри, ₽ на UI.
- Без `localStorage`/`sessionStorage` где артефакт окружения; состояние из API/SDK.
